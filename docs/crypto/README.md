# 密码学

密码学方向涵盖古典密码、现代密码及其在 CTF 中的应用。

## 内容大纲

- 古典密码（凯撒、维吉尼亚、栅栏等）
- 对称加密（DES、AES）
- 非对称加密（RSA、ECC）
- 哈希函数（MD5、SHA 系列）
- 数字签名
- 编码基础（Base64、Hex 等）
- RSA 攻击方法
- 分组密码攻击
- 哈希碰撞与长度扩展攻击

## 学习路线

1. 掌握常见编码和古典密码
2. 理解对称加密和非对称加密原理
3. 学习 RSA 的各种攻击方法
4. 了解分组密码的工作模式及攻击
5. 掌握哈希函数的安全性问题
