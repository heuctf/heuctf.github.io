# 逆向工程

逆向工程方向涉及对程序的分析和理解，是二进制安全的基础。

## 内容大纲

- 汇编语言基础
- 静态分析工具（IDA Pro、Ghidra）
- 动态调试（x64dbg、GDB）
- PE/ELF 文件格式
- 反调试与反编译技术
- 脱壳技术
- 脚本语言逆向（Python、Lua 等）
- Android 逆向
- 混淆与去混淆

## 学习路线

1. 掌握 x86/x64 汇编语言
2. 熟练使用 IDA Pro 和 Ghidra 进行静态分析
3. 学习动态调试技术
4. 了解常见的加壳和保护技术
5. 探索移动端逆向和其他平台
