# 杂项

杂项方向涵盖广泛的安全知识和技能，是 CTF 中的万金油。

## 内容大纲

- 隐写术（图片、音频、视频隐写）
- 流量分析（Wireshark、tcpdump）
- 取证分析（内存取证、磁盘取证）
- OSINT 开源情报
- 编程与脚本
- 社会工程学
- 区块链安全
- Forensics 工具使用

## 学习路线

1. 熟悉各类隐写工具和技术
2. 掌握流量分析基础
3. 学习取证分析工具（Volatility 等）
4. 提升编程能力，编写自动化脚本
5. 拓展知识面，关注新兴技术
