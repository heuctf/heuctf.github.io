\section{概述}
许多互联网网站仍然容易遭受网页缓存欺骗攻击。在这种攻击中，恶意行为者会“欺骗”网络服务器，以提供他/她不被允许访问的信息。例如，在简单的电子商务网站，我们有两种用户类型：客户和管理员。用户只能查看与其账号相关的订单，他还被限制查看网站的部分页面。在网页缓存欺骗攻击中，用户能够访问这些受限页面。

手动检查所有链接可能非常繁琐且疲惫，对渗透测试人员来说尤其如此。在本指南中，我将教你如何使用 BURP 套件自动检查易受攻击的链接。

\section{要求}
\begin{itemize}
    \item 安装 Burpsuite（可以使用社区版）。
    \item 准备一个易受攻击的网站，互联网上有许多免费可用于此测试的易受攻击网页应用，如 OWASP 果汁 Shop、Damn Vulnerable Web Application 和 Web Goat 等众多网页应用。对于本指南，我们将使用 OWASP 果汁店。
\end{itemize}

\section{Burpsuite 安装}
我们首先会在系统上安装 Burpsuite。在 Linux 上安装 Burpsuite，我们下载 Burpsuite 安装程序并赋予其执行权限。

\begin{lstlisting}
cd ~/Downloads
chmod +x burpsuite_community_linuxv2022_8_4.sh
./burpsuite_community_linux_v2022_8_4.sh
\end{lstlisting}

安装面板会出现，帮助你完成安装配置。安装时，Burpsuite 还会检查运行所需的要求是否达成。

\section{Autorize 扩展配置}
当使用 burpsuite 发起网页缓存欺骗攻击时，需要一个称为 autorize 的扩展，这就是我们将用来自动化链接检查任务的工具。

对于 autorize 扩展要工作，我们首先需要配置一个 Burpsuite 支持的 Python 环境。前往 Jython 下载页面，下载 Jython 独立版。

要在 burpsuite 上配置 python 环境，我们导航到「扩展器」标签，并选择我们 Jython 独立文件的位置。

配置完成后，我们可以安装 Autorize。进入 BAppStore 标签页，在这个标签页上，你可以安装 BURPsuite 用于各种网站测试的扩展。在该标签页，我们搜索 autorize 并安装在 Burpsuite 中。

安装完成后，你可以看到新增一个 Autorize 标签页。我们现在可以运行我们的目标网站了。

\section{安装和搭建 OWASP 果汁店}
本指南将测试 OWASP 果汁店，我们将运行 docker 化的 OWASP 果汁店来应对此次攻击。第一步是安装 docker，并拉取已 docker 化的 OWASP 果汁店。

\begin{lstlisting}
docker pull bkimminich/juice-shop
docker run --rm -p 3000:3000 bkimminich/juice-shop
\end{lstlisting}

juice-shop 的运行实例现在可以在 0.0.0.0:3000 访问，通过任何浏览器均可访问。

\section{网络缓存欺骗攻击}
确保所有设备都已上线并配置好，准备进行网页缓存欺骗攻击（确保你的易受攻击的网页应用正在运行，本指南中我们正在使用 OWASP Juice-Shop，并确保 Burpsuite 已经启动并完成代理运行设置配置，我们可以通过使用 BurpSuite 内置浏览器验证）。

\subsection{捕获低级别用户 Cookie}
从拥有低级权限的客户端浏览网页应用的会话中捕获 Cookie，是启动网络缓存欺骗攻击的第一步。我们使用代理到 Burpsuite 的浏览器，导航以访问网页应用。我们可以尝试导航到网页应用中不同的页面，在 BurpSuite 上，我们可以看到各种向网页应用提出的请求。

\subsection{添加捕获的头部和 Cookie 以自动化}
在我们拥有低权限用户 Cookie 和授权头之后，我们现在可以导航到 Autorize 标签页添加它们。在 autorize 标签页上，有一个带有「临时头部」标题的文本框，这就是我们添加 Cookie 和头部的地方。这个流程是自动化的，我们只需要点击下方的「取用标题」按钮。

在拦截过滤器中，确保添加「仅限范围物品」过滤，在发动网络缓存欺骗攻击前进行过滤。你也可以选择「检查未认证」，这非常推荐，因为该网页可以被没有账户的用户访问，但会有访问限制。最后，我们通过点击「自动开始」按钮完成配置。

我们现在可以回到网页应用，以高权限用户登录并浏览网站上的页面。

\subsection{检查 Autorize 的结果}
在 autorize 标签页中，我们可以看到被绕过的链接。Autorize 可以重复高权限用户账户向网页应用发起的类似请求，但此时使用的是低权限用户的 Cookie。这类似于低权限用户逐条手动测试这些链接，Autorize 的主要功能就是自动化这些链接的检查工作。

\section{结论}
在上述指南中，我们能够针对一个目标网站启动网页缓存欺骗攻击测试。Autorize 扩展已被用于自动化检查链接的过程，因此花费的时间更少，相较于手动检查每个链接。autorize 扩展非常有用，尤其是用于漏洞赏金猎杀。所有用于检测这些网络漏洞的工具在互联网上都是免费存在的。许多互联网网站仍然容易受到网页缓存欺骗攻击的威胁。
