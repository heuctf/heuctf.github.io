## 用户需求

为哈尔滨工程大学网络安全社团的知识库项目编写一份专业、完整的 README 文档。

## 产品概述

这是一个基于 VuePress 和 vuepress-theme-plume 主题构建的社团知识库 Wiki 系统，部署在 GitHub Pages 上，用于存储和分享网络安全相关的技术知识、学习笔记、博客文章等内容。

## 核心功能

- 展示项目简介和技术栈
- 提供快速开始指南（环境要求、安装、本地运行）
- 说明项目结构和目录用途
- 提供社团成员贡献文章的指南
- 说明 GitHub Pages 部署流程
- 提供相关链接和联系方式

## 技术栈

- **静态站点生成器**：VuePress 2.0.0-rc.26
- **主题**：vuepress-theme-plume 1.0.0-rc.192
- **构建工具**：Vite (通过 @vuepress/bundler-vite)
- **运行时环境**：Node.js ^20.19.0 || >=22.0.0
- **部署平台**：GitHub Pages

## 实现方案

重写 `README.md` 文件，包含以下模块：

1. **项目标题与徽章**：项目名称、状态徽章、许可证等
2. **项目简介**：社团知识库的定位和用途
3. **技术栈**：列出核心技术组件
4. **快速开始**：环境要求、安装依赖、本地运行、构建命令
5. **项目结构**：目录结构说明
6. **贡献指南**：如何添加新文章、撰写规范
7. **部署说明**：GitHub Pages 部署流程
8. **相关链接**：VuePress 文档、主题文档、社团联系方式
